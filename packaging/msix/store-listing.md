## Description (Tell customers what your product does - max 10,000 characters)

My Markdown Viewer opens your .md files and shows them beautifully - with real mathematics and real diagrams, not just text. It is tiny, starts instantly and keeps everything on your device.

MERMAID DIAGRAMS, BUILT IN
Write a diagram as text inside a ```mermaid code block and see it drawn right in your document: flowcharts, sequence diagrams, class diagrams, state diagrams, entity-relationship diagrams, Gantt charts, pie charts, mind maps, timelines, user journeys, git graphs and more. The Mermaid engine is included in the app, so diagrams render offline, instantly, and follow your light or dark theme.

LATEX MATH, TYPESET NATIVELY
Put LaTeX between $ ... $ for inline formulas or $$ ... $$ for display equations. Fractions, roots, sums, integrals, limits, matrices, Greek letters, vectors, accents, determinants, binomials and much more are rendered as crisp, selectable, scalable equations using your system's native math rendering (MathML). Perfect for physics, engineering, statistics and machine-learning notes, lecture material and research drafts.

HTML, SVG AND MATHML EMBEDS
Need something Markdown cannot express? Raw HTML is supported, so you can embed hand-drawn SVG diagrams, charts, animated graphics, collapsible sections, keyboard-key styling and CSS grid layouts, or write equations directly in MathML.

A COMPLETE MARKDOWN READER
Tables, task lists, footnotes, strikethrough, heading anchors, code blocks, block quotes, images and links. Links to other Markdown files open inside the viewer, and relative images just work.

BUILT FOR EVERYDAY USE
- Open files from the File menu, by drag and drop, or by double-clicking a .md file
- Live reload: the view refreshes as soon as you save in your editor
- Find in page (Ctrl+F), zoom (Ctrl +/-/0), print or save as PDF (Ctrl+P)
- Light, dark or follow-the-system theme
- Remembers your theme, zoom level and recent files
- Open the current file in your editor with one shortcut

SMALL AND PRIVATE
The app is only a few megabytes. It has no account, no ads, no analytics and no telemetry, and your documents never leave your computer. My Markdown Viewer is open source (MIT): https://github.com/sunaram/markdown-viewer
