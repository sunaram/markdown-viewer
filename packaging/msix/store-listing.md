## Short description (max 100 characters)

A tiny, fast Markdown viewer with LaTeX math, Mermaid diagrams and HTML/SVG support.

## Description

Markdown Viewer opens your .md files and shows them the way they were meant to look - quickly, and with a download of
only a few megabytes.

**Everything renders on your device**
- Markdown: tables, task lists, footnotes, strikethrough, heading anchors
- Math: write LaTeX between $ ... $ or $$ ... $$ and get crisp, native equations (MathML)
- Diagrams: flowcharts, sequence, class, state, ER, Gantt, pie, mind maps and more with Mermaid
- Raw HTML, inline SVG and MathML are supported, so you can embed charts, animations and custom layouts

**Made for reading and working**
- Open files from the File menu, by drag and drop, or by double-clicking a .md file
- Live reload: the view updates as soon as you save the file in your editor
- Find in page, zoom, print or save as PDF
- Light, dark or follow the system theme
- Remembers your theme, zoom and recent files
- Follow links between Markdown files

**Private by design**
No account, no ads, no analytics, no telemetry. Your documents never leave your computer.
